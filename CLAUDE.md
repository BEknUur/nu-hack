# Saya — проект

## Что это и зачем
Геопространственная платформа для анализа городской жары и климатической адаптации.
По реальным спутниковым данным показывает, где перегревается поверхность города,
и рекомендует куда сажать деревья (охлаждение улиц) и ставить солнечные панели.
Хакатон SmartEarth 2026, трек "Urban Intelligence: Smart and Sustainable Cities".

Это новый продукт с новым тезисом — городская жара, а не риелторский анализ.
Брендинг, README и UI ориентированы на тепло и климат.

## Стек (не менять без причины)
- Frontend: React 19 + TypeScript + Vite + MapLibre GL + mapbox-gl-shadow-simulator
- Backend: FastAPI + Python 3.12
- Кэш/БД: Redis + PostgreSQL/Supabase
- Данные: OpenStreetMap через Overpass API, Google Earth Engine (Landsat/Sentinel-2), PVGIS
- Docker + Docker Compose

## Критическое различие данных
"Solar exposure" (существующий режим) = сколько солнца попадает на поверхность за день.
Это НЕ температура. Газон и парковка могут получить одинаковую экспозицию, но
асфальт нагреется до 50°C, а трава останется прохладной.
"LST" (Land Surface Temperature) = реально измеренная температура поверхности
со спутника Landsat 8/9. Только это называть температурой в UI и коде.

## Данные LST/NDVI
GEE-скрипт (Google Earth Engine) скачивает летний медианный снимок Астаны:
- Landsat 8/9 Collection 2 L2, бэнд ST_B10 -> LST в °C
  (формула: value × 0.00341802 + 149.0 − 273.15)
- Sentinel-2 SR Harmonized, NDVI = (B8 − B4) / (B8 + B4), 10 м
- Маскировка облаков: QA_PIXEL для Landsat; SCL (классы 3,8,9,10,11) для Sentinel-2
- Результат: CSV-сетка 100 м с колонками lon, lat, LST, NDVI [, exposure]
  кладётся рядом с backend (astana_grid_100m.csv)
Пока CSV нет — backend генерирует синтетическую сетку для разработки.

## Модель приоритета озеленения
priority = w_lst × LST_norm + w_veg × (1 − NDVI_norm) + w_exp × exposure_norm
где нормировка (x − min) / (max − min) по всей сетке.
Рекомендуемые веса по умолчанию: w_lst=0.55, w_veg=0.35, w_exp=0.10
(вынести в конфиг, не хардкодить).

## Модель охлаждения (источники в комментариях кода)
- +10% кроны ≈ −0.8°C воздуха; +30% ≈ −1.5°C (npj Urban Sustainability 2025)
- Консервативный наклон: −0.05°C на +1% кроны
- Потолок: 5°C (PNAS: ≥40% покрытия → −4..5°C)
- В волну жары (опция): ×0.70 (устьица закрываются)
CO2: ~21 кг/дерево/год (приблизительно, помечать как оценку).
Сценарий принимает target_canopy_pct ИЛИ n_trees (взаимно вычислять).

## Ранжирование точек посадки
Сортировка по priority desc + greedy spacing (Haversine ≥ 80 м между точками).

## Конвенции
- Минимальные диффы, не трогать рабочий shadow-движок и существующие эндпоинты.
- P0 обязателен, P1 — если останется время.
- После каждого шага запустить и проверить /health + новый эндпоинт.
- Не коммитить .env / ключи.
