## Демо-сценарий (3 минуты)

1. Открываем карту Астаны → включаем Heat слой → парки синие, проспекты красные
2. «Вот квартал у школы — раскалённый асфальт, нет деревьев, дети ходят тут каждый день»
3. Рисуем зону → запускаем оптимизатор → топ точек посадки подсвечивается + AI-объяснение
4. Жмём «смоделировать +30% кроны» → before/after, число: **−1.5 °C, −Y тонн CO2/год**
5. Переключаем на Solar → топ крыш по выработке, **+Z МВт·ч/год, офсет CO2**
6. Закрываем: «работает для любого города из OSM + Landsat, данные открытые, эффект измеримый»
